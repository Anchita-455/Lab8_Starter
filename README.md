How are graceful degradation and service workers related? (Answer this after doing the part below)

Graceful degradation and service workers are related because graceful degradation focuses on ensuring that a web application still works, even when ideal conditions are not available. Service workers help achieve this by allowing parts of the web app to continue functioning when the network is unavailable, such as serving cached pages and resources offline.
